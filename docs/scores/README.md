# BetterGarmin scores

This folder documents the formula, inputs, and research sources behind every
score BetterGarmin calculates itself (as opposed to scores it simply displays
from Garmin's own stored data).

Nothing is calculated yet — the current build only displays Garmin's native
values (sleep score, Body Battery, HRV, training load/effect, VO2max where
Garmin provides it). As BetterGarmin's own scores (Energy Reserve curve,
Stress timeline, Readiness, Training Status, Fitness/Fatigue/Form, aerobic
efficiency, cardiovascular-age insight) ship, each gets its own page here
with:

- The exact formula and inputs used
- The published sports-science or sleep-science sources it's based on
- How it's clearly labeled in the UI as a BetterGarmin estimate, not Garmin's
  official number
